Your own wallpapers: put .jpg, .png or .webp images here (16:9 looks best, e.g. 1920×1080), build, and pick them
on the TV in Free My TV > Home Settings > Wallpaper. The file name is the name shown ("black-sand.jpg" = "Black Sand").
The images stay out of git (.gitignore), so they're never published with the code.
